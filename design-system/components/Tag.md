# Tag

An uppercase condensed label for race type, IAU labels, cups and result status — text, not a pill.

## When to use
Race type and surface (`default` or `muted`), IAU labels and championships (`brand`), the DUV-Cup (`solid`), and result status with a dot (`status`).

## What you provide
`children` (the word), `tone`, optional `status` (`success` | `warning`) for a 6px dot.

## Rules
Colour never stands alone: a status dot always has its word. Only IAU, championships and DUV-Cup take red.
